# 두근두근 영어 - 영어 울렁증 극복 서비스

- 배포 주소: https://hongsehwan.github.io/uiuxprogramming/
- 저장소 주소: https://github.com/HongSehwan/uiuxprogramming

## 학습자와 목표
- 주요 사용자: 영어에 대한 두려움이나 부담을 느끼는 학습자
- 목적: 영어의 기본기를 탄탄하게 익히고 영어에 대한 자신감 향상
- 주요 행동: 매일 수준에 맞는 영어 단어와 문장을 반복 학습, 원어민과 화상통화로 소통, 게임 요소가 포함된 학습 콘텐츠 진행

## 7주차 학습자의 흐름
1. 카메라 활용에 동의하고 '화상통화 설정 시작하기'를 누른다.
2. 안내 팝업에서 '동의하고 설정 시작하기'를 누른다.
3. 닉네임을 입력한다.
4. 학습 단어 수(3개/5개/10개)과 문장 포함 여부, 문장 수를 선택한다.
5. 입력한 내용을 확인하고 '설정 완료하기'를 누른다. 필요하면 '수정하기' 또는 '다시 설정하기'를 누른다.

## 새로 추가한 기능(중간시험 레포트): 오늘의 단어 학습

### 기능 설명
7주차 흐름의 끝인 설정 완료 화면에 '오늘의 단어 학습 시작하기' 버튼을 연결
앞에서 입력한 닉네임과 선택한 학습 단어 수, 문장 옵션에 맞춰 문제가 만들어지고 학습자는 한국어 뜻을 보고 영어 단어와 문장을 직접 입력하며 학습 진행

### 연결 지점과 설정값 반영
- 연결 지점: 설정 완료 화면 -> 오늘의 단어 학습 -> 결과 -> 설정 완료 화면
- 닉네임 -> 학습 화면 제목과 결과 문구에 표시
- 출제 단어 수 (3개, 5개, 10개, 단어 순서는 램덤)
- 문장 포함 / 문장 수 -> 단어 뒤에 선택한 개수만큼 문장 문제 추가

### 인터랙션 시나리오
1. 학습 시작
- 사용자 행동: 설정 완료 화면에서 '오늘의 단어 학습 시작하기'를 누른다.
- 반응: 설정 화면을 닫고 학습 화면을 연다. "학습 단어 수 5개 설정에 맞춰 단어 5개와 문장 2개를 준비했습니다."처럼 준비한 문제를 안내하고 입력창에 초점을 둔다.

2. 정답 확인
- 사용자 행동: 한국어 뜻을 보고 영어를 입력한 뒤 '정답 확인'을 누르거나 엔터를 누른다.
- 확인할 조건: 입력값이 비었는가? 한글이 섞였는가? 정답과 같은가? (대소문자, 앞뒤 공백, 문장부호 . , ? ! 는 구분하지 않음)
- 성공 반응: "정답입니다! 잘 입력했어요." 안내를 초록색으로 보여 주고 입력창을 잠근다.
- 오류 반응
  - 빈 값: "답이 비어 있습니다. 한국어 뜻에 맞는 영어를 입력한 뒤 '정답 확인'을 눌러 주세요." 입력창을 빨간 테두리로 표시하고 초점을 둔다.
  - 한글 입력: "한글이 입력되었습니다. 한/영 키를 눌러 영어로 바꾼 뒤 다시 입력해 주세요." (기회는 줄어들지 않음)
  - 오답: "정답이 아닙니다. 철자를 확인하고 다시 입력해 주세요. (남은 기회 2번)" 입력값은 지우지 않아 바로 고칠 수 있다.
  - 3번 모두 틀림: 정답을 알려 주고 틀린 문제로 기록한다.
- 다음 행동: '다음 문제' 버튼(마지막 문제에서는 '결과 보기')을 누른다.

3. 힌트 보기
- 사용자 행동: '힌트 보기'를 누른다.
- 반응: 단어는 첫 글자와 글자 수, 문장은 첫 단어와 단어 수를 보여 준다. 문제마다 한 번만 쓸 수 있고, 사용하면 버튼이 비활성화된다.

4. 건너뛰기
- 사용자 행동: '이 문제 건너뛰기'를 누른다.
- 반응: 정답을 보여 주고 틀린 문제로 기록한다. '다음 문제' 버튼으로 이어진다.

5. 학습 그만두기 (취소)
- 사용자 행동: '학습 그만두기'를 누른다.
- 반응: 바로 종료하지 않고 "학습을 그만둘까요?" 확인 창을 보여 준다.
  - '계속 학습하기': 입력하던 답, 본 힌트, 진행 상황을 그대로 유지하고 학습 화면으로 돌아간다.
  - '그만두고 돌아가기': 이번 학습 상태를 초기화하고 설정 완료 화면으로 돌아간다. 설정값은 유지된다.

6. 결과 확인
- 반응: "OO님은 7문제 중 5문제를 맞혔습니다. (힌트 사용 1번, 건너뛴 문제 1개)"처럼 결과를 보여 준다.
  - 틀린 문제가 있는 경우: '다시 볼 문제' 목록(뜻 -> 정답)과 '틀린 문제 N개만 다시 풀기' 버튼을 보여 준다.
  - 틀린 문제가 없는 경우 (결과 없음): 목록 대신 "틀린 문제가 없습니다. 모두 맞혔어요!" 안내를 보여 주고 다시 풀기 버튼을 숨긴다.
- 다음 행동: '틀린 문제만 다시 풀기', '처음부터 다시 풀기'(같은 설정, 새로 섞은 단어), '학습 설정으로 돌아가기' 중 선택한다.

7. 다시 설정하기
- 설정 완료 화면에서 '다시 설정하기'를 누르면 설정값과 함께 학습 상태(문제, 점수, 틀린 문제 목록)도 초기화된다.

## 테스트 기록
크롬 브라우저에서 데스크톱(1280px)과 모바일(360px) 화면 크기로 직접 조작하며 확인 완료

| 구분 | 테스트 방법 | 결과 |
| --- | --- | --- |
| 정상 경로 | 닉네임 '홀길동', 3개, 문장 1개 선택 후 학습 시작 | "단어 3개와 문장 1개를 준비했습니다", "문제 1 / 4" 표시 |
| 정상 경로 | 정답을 대문자와 앞뒤 공백을 섞어 입력 | 정답으로 처리, 다음 문제 버튼 표시 |
| 오류 | 빈 값으로 '정답 확인' | 빈 값 안내, 빨간 테두리, 입력창에 초점 |
| 오류 | '사과'처럼 한글 입력 후 엔터 | 한/영 전환 안내, 기회 줄지 않음 |
| 오류 | 오답 3번 입력 | 남은 기회 2번 -> 1번 안내 후 정답 공개, 입력창 잠김 |
| 힌트 | 단어 / 문장 문제에서 '힌트 보기' | "첫 글자는 'w'이고, 모두 5글자입니다." / "첫 단어는 'Nice'이고, 모두 4단어입니다.", 버튼 비활성화 |
| 건너뛰기 | '이 문제 건너뛰기' | 정답 공개, 결과의 건너뛴 문제 수와 틀린 문제 목록에 반영 |
| 취소 | 답을 입력하던 중 '학습 그만두기' -> '계속 학습하기' | 입력값과 힌트가 그대로 유지됨 |
| 취소 | '학습 그만두기' -> '그만두고 돌아가기' | 설정 완료 화면으로 이동, 다시 시작하면 "문제 1 / 6, 맞힌 문제 0개"부터 시작 |
| 결과 | 1문제 오답, 1문제 건너뛰기 후 결과 보기 | "4문제 중 2문제를 맞혔습니다", 틀린 문제 2개 목록과 '틀린 문제 2개만 다시 풀기' 버튼 표시 |
| 다시 풀기 | '틀린 문제 2개만 다시 풀기' | "틀린 문제 2개를 다시 풀어 봅니다" 안내, "문제 1 / 2"로 시작 |
| 결과 없음 | 다시 풀기에서 모두 정답 | "틀린 문제가 없습니다. 모두 맞혔어요!" 표시, 다시 풀기 버튼과 목록 숨김 |
| 다시 풀기 | '처음부터 다시 풀기' | 같은 설정으로 "문제 1 / 4, 맞힌 문제 0개"부터 다시 시작 |
| 수정 | 확인 화면에서 '수정하기' | 선택한 학습 단어 수(10개) 유지 |
| 다시 설정 | '다시 설정하기' 후 닉네임 '이순신', 10개, 문장 미포함으로 다시 시작 | 닉네임과 단어 수 초기화 확인, 새 학습 화면에 "이순신님", "단어 10개", "문제 1 / 10" 반영 |
| 반응형 | 모바일 360px에서 전체 흐름 조작 | 버튼과 정보가 한 열로 배치, 겹침이나 가로 스크롤 없음 |
| 다크 테마 | 다크 테마에서 학습과 결과 화면 확인 | 글자와 버튼 색 구분 가능, 비활성 버튼 회색 표시 |
