# 두근두근 영어 - 영어 울렁증 극복 서비스

- 배포 주소: https://hongsehwan.github.io/uiuxprogramming/
- 저장소 주소: https://github.com/HongSehwan/uiuxprogramming

## 학습자와 목표
- 주요 사용자: 영어에 대한 두려움이나 부담을 느끼는 학습자
- 목적: 영어의 기본기를 탄탄하게 익히고 영어에 대한 자신감 향상
- 주요 행동: 매일 수준에 맞는 영어 단어와 문장을 반복 학습, 원어민과 화상통화로 소통, 게임 요소가 포함된 학습 콘텐츠 진행

## 9주차 추가한 기능: 원어민 화상수업 예약 폼

### 추가·수정한 내용
- 서비스의 주요 행동인 '원어민 화상통화'와 연결되는 **원어민 화상수업 예약 폼** 추가
- 상단 메뉴에 '화상수업 예약' 링크 추가
- 학습 설정의 **닉네임 입력칸 개선** (`#nickname-field`): `필수` 표시, 1자 이상 10자 이하 조건 도움말, 입력 중 글자 수(`0 / 10자`) 표시, 비어 있으면 오류 문구를 보여 주고 입력하면 바로 해제
- 학습 설정의 **문장 포함 조건부 입력 개선**: '문장도 함께 학습할게요'를 체크하면 문장 수 영역이 나타나고 라디오 버튼의 `disabled`가 해제되며, 체크를 풀면 영역이 숨겨지고 다시 `disabled` 처리됨
- 필수 항목은 `<span class="required">필수</span>`로 표시하고 입력칸에 `required`, `minlength`, `maxlength` 속성 추가
- 입력 항목: 예약자 이름(텍스트), 수업 날짜(날짜), 수업 시간(선택 목록), 수업 주제(라디오), 선생님께 전할 말(여러 줄 텍스트), 피드백 이메일 받기(체크박스)
- 모든 입력 요소에 label을 연결하고, 입력 조건 도움말을 `aria-describedby`로 연결
- 예약 내용은 브라우저 저장 기능(localStorage)에 저장하고 '나의 예약 내역'에 표시

### 입력 조건
| 항목 | 조건 | 오류 문구 예시 |
| --- | --- | --- |
| 닉네임 (학습 설정) | 필수, 1~10자 | "오류: 닉네임이 비어 있습니다. 1자 이상 10자 이하로 입력해 주세요." |
| 예약자 이름 | 필수, 2~10자 | "오류: 이름이 너무 짧습니다. 2자 이상 입력해 주세요." |
| 수업 날짜 | 필수, 오늘 이후 날짜 | "오류: 지난 날짜는 예약할 수 없습니다. 오늘 이후의 날짜를 선택해 주세요." |
| 수업 시간 | 필수 | "오류: 수업 시간을 선택해 주세요." |
| 선생님께 전할 말 | 필수, 10자 이상 (최대 200자) | "오류: 선생님께 전할 말을 10자 이상 적어 주세요. (5자 더 필요)" |
| 피드백 이메일 | 체크박스 선택 시에만 필수, @와 . 포함 | "오류: 이메일 형식이 아닙니다. name@example.com 처럼 입력해 주세요." |

### 구현 내용
- **조건부 입력**: '수업이 끝난 뒤 학습 피드백을 이메일로 받기'를 체크하면 이메일 입력 영역이 나타나고 `disabled`가 해제된다. 체크를 풀면 영역이 숨겨지고 `disabled` 처리되며 입력값과 오류도 지워진다.
- **입력 중 피드백**: 이름은 "3 / 10자", 전할 말은 "5 / 200자 (5자 더 필요)" -> "18 / 200자 (조건 충족)"처럼 글자 수와 조건 충족 여부를 문구로 표시한다.
- **오류 표시와 해제**: 오류가 난 칸은 빨간 테두리와 "오류:"로 시작하는 문구를 함께 보여 준다. 오류가 있는 칸은 입력할 때마다 다시 검사해서 올바르게 고치면 바로 오류가 사라진다.
- **제출 처리**: `form`의 `submit` 이벤트에서 `preventDefault()` 후 모든 항목을 검사한다.
  - 조건 미충족: 제출을 막고 "수정이 필요한 항목: 예약자 이름, 수업 시간"처럼 안내한 뒤 첫 번째 오류 칸으로 초점을 옮긴다.
  - 제출 중: "예약하는 중..." 문구를 표시하고 제출·다시 작성 버튼을 비활성화하여 중복 제출을 막는다. (`isReserving` 변수로 한 번 더 확인)
  - 성공: 1초 뒤 localStorage에 저장하고 완료 안내를 표시한 뒤 폼을 비운다.
  - 실패: 입력 내용은 그대로 두고 실패 안내를 표시하며, 버튼을 다시 활성화해 바로 다시 시도할 수 있다.
- **다시 작성**: 입력값과 함께 오류 문구, 글자 수 안내, 조건부 영역, 상태 문구, 버튼 상태가 모두 처음으로 돌아간다.

### 실패 처리 조건과 코드 위치
- `script.js`의 `saveReservation()` 함수
  1. **같은 날짜·같은 시간에 이미 예약이 있는 경우**: 저장하지 않고 "예약에 실패했습니다. ... 이미 예약된 시간입니다." 안내, 수업 시간 칸에 오류 표시 후 초점 이동
  2. **브라우저 저장 공간을 사용할 수 없는 경우**: `try...catch`로 잡아서 실패 안내 표시

### 확인 순서
1. 아무것도 입력하지 않고 '예약 신청하기' -> 제출이 막히고 수정할 항목 목록과 각 칸의 오류 문구 표시, 이름 칸에 초점
2. 이름에 '홍' 입력 -> "2자 이상 입력" 오류 / '홍길동'으로 수정 -> 오류 해제
3. 전할 말에 'hello' 입력 -> "5자 더 필요" / 10자 이상 입력 -> "조건 충족"(초록색)
4. 피드백 받기 체크 -> 이메일 칸 표시·입력 가능 / 'abc' 입력 후 제출 -> 이메일 형식 오류 / 체크 해제 -> 칸이 숨겨지고 disabled
5. 날짜·시간 선택 후 제출 -> "예약하는 중..." 표시, 버튼 비활성화 -> 1초 뒤 완료 안내와 예약 내역 추가
6. 같은 날짜·시간으로 한 번 더 예약 -> 실패 안내, 입력 내용 유지, 시간을 바꾸면 오류 해제 후 다시 신청 가능
7. 입력 도중 '다시 작성' -> 입력값, 오류 문구, 글자 수, 조건부 영역, 버튼 상태 모두 초기화

## 7주차 학습자의 흐름
1. 카메라 활용에 동의하고 '화상통화 설정 시작하기'를 누른다.
2. 안내 팝업에서 '동의하고 설정 시작하기'를 누른다.
3. 닉네임을 입력한다.
4. 학습 단어 수(3개/5개/10개)과 문장 포함 여부, 문장 수를 선택한다.
5. 입력한 내용을 확인하고 '설정 완료하기'를 누른다. 필요하면 '수정하기' 또는 '다시 설정하기'를 누른다.

## 새로 추가한 기능(중간시험 레포트): 오늘의 단어 학습

### 기능 설명
7주차 흐름의 끝인 설정 완료 화면에 '오늘의 단어 학습 시작하기' 버튼을 연결
앞에서 입력한 닉네임과 선택한 학습 단어 수, 문장 옵션에 맞춰 문제가 만들어지고 학습자는 한국어 뜻을 보고 영어 단어와 문장을 직접 입력하며 학습 진행

### 연결 지점과 설정값 반영
- 연결 지점: 설정 완료 화면 -> 오늘의 단어 학습 -> 결과 -> 설정 완료 화면
- 닉네임 -> 학습 화면 제목과 결과 문구에 표시
- 출제 단어 수 (3개, 5개, 10개, 단어 순서는 램덤)
- 문장 포함 / 문장 수 -> 단어 뒤에 선택한 개수만큼 문장 문제 추가

### 인터랙션 시나리오
1. 학습 시작
- 사용자 행동: 설정 완료 화면에서 '오늘의 단어 학습 시작하기'를 누른다.
- 반응: 설정 화면을 닫고 학습 화면을 연다. "학습 단어 수 5개 설정에 맞춰 단어 5개와 문장 2개를 준비했습니다."처럼 준비한 문제를 안내하고 입력창에 초점을 둔다.

2. 정답 확인
- 사용자 행동: 한국어 뜻을 보고 영어를 입력한 뒤 '정답 확인'을 누르거나 엔터를 누른다.
- 확인할 조건: 입력값이 비었는가? 한글이 섞였는가? 정답과 같은가? (대소문자, 앞뒤 공백, 문장부호 . , ? ! 는 구분하지 않음)
- 성공 반응: "정답입니다! 잘 입력했어요." 안내를 초록색으로 보여 주고 입력창을 잠근다.
- 오류 반응
  - 빈 값: "답이 비어 있습니다. 한국어 뜻에 맞는 영어를 입력한 뒤 '정답 확인'을 눌러 주세요." 입력창을 빨간 테두리로 표시하고 초점을 둔다.
  - 한글 입력: "한글이 입력되었습니다. 한/영 키를 눌러 영어로 바꾼 뒤 다시 입력해 주세요." (기회는 줄어들지 않음)
  - 오답: "정답이 아닙니다. 철자를 확인하고 다시 입력해 주세요. (남은 기회 2번)" 입력값은 지우지 않아 바로 고칠 수 있다.
  - 3번 모두 틀림: 정답을 알려 주고 틀린 문제로 기록한다.
- 다음 행동: '다음 문제' 버튼(마지막 문제에서는 '결과 보기')을 누른다.

3. 힌트 보기
- 사용자 행동: '힌트 보기'를 누른다.
- 반응: 단어는 첫 글자와 글자 수, 문장은 첫 단어와 단어 수를 보여 준다. 문제마다 한 번만 쓸 수 있고, 사용하면 버튼이 비활성화된다.

4. 건너뛰기
- 사용자 행동: '이 문제 건너뛰기'를 누른다.
- 반응: 정답을 보여 주고 틀린 문제로 기록한다. '다음 문제' 버튼으로 이어진다.

5. 학습 그만두기 (취소)
- 사용자 행동: '학습 그만두기'를 누른다.
- 반응: 바로 종료하지 않고 "학습을 그만둘까요?" 확인 창을 보여 준다.
  - '계속 학습하기': 입력하던 답, 본 힌트, 진행 상황을 그대로 유지하고 학습 화면으로 돌아간다.
  - '그만두고 돌아가기': 이번 학습 상태를 초기화하고 설정 완료 화면으로 돌아간다. 설정값은 유지된다.

6. 결과 확인
- 반응: "OO님은 7문제 중 5문제를 맞혔습니다. (힌트 사용 1번, 건너뛴 문제 1개)"처럼 결과를 보여 준다.
  - 틀린 문제가 있는 경우: '다시 볼 문제' 목록(뜻 -> 정답)과 '틀린 문제 N개만 다시 풀기' 버튼을 보여 준다.
  - 틀린 문제가 없는 경우 (결과 없음): 목록 대신 "틀린 문제가 없습니다. 모두 맞혔어요!" 안내를 보여 주고 다시 풀기 버튼을 숨긴다.
- 다음 행동: '틀린 문제만 다시 풀기', '처음부터 다시 풀기'(같은 설정, 새로 섞은 단어), '학습 설정으로 돌아가기' 중 선택한다.

7. 다시 설정하기
- 설정 완료 화면에서 '다시 설정하기'를 누르면 설정값과 함께 학습 상태(문제, 점수, 틀린 문제 목록)도 초기화된다.
