# 두근두근 영어 - 학습 설정

## 학습자와 목표
- 학습자: 영어를 학습하는 사람
- 목표: 수준에 맞는 영어 단어와 문장을 익히고 활용한다.

## 학습자의 흐름
1. 카메라 활용에 동의하고 '학습 설정 시작하기'를 누른다.
2. 닉네임을 설정하고 보이는 영어 단어와 문장을 학습한다.
3. 오늘 배운 영어 단어와 문장을 사용하여 화상통화를 통해 원어민과 소통한다.
4. 간단한 게임을 통해 학습한 영어를 복습한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터랙션 시나리오
1. 시작과 카메라 활용 안내
- 행동, 이벤트: 기존 동의 체크박스를 선택하고 '학습 설정 시작하기'를 클릭한다.
- 조건: 카메라 활용 동의가 선택되었는가?
- 반응, 다음 상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 설명하는 안내 팝업이 열린다.
                팝업에서 '돌아가기'를 누르거나 Esc를 누르면 동의를 해제하고 시작 화면에 남는다.
                '동의하고 설정 시작하기'를 누르면 영어 단어와 문장 학습 화면을 연다.
2. 닉네임과 학습 영어 입력
- 행동, 이벤트: 닉네임을 설정하고 보이는 영어 단어와 문장을 따라 적으며 학습을 진행한다.
- 조건: 앞뒤 공백을 지운 영어 단어와 문장이 비어 있는가?
- 반응, 다음상태: 비어있으면 같은 화면에 오답을 표시하고 입력창에 초점을 둔다.
                값이 있고 동일하게 입력했으면 다음 학습 단어와 문장으로 넘어간다.
3. 원어민과 소통
- 행동, 이벤트: 원어민과 화상통화가 연결되면 마이크를 켜 대화한다.
- 조건: 카메라가 있는가? 마이크가 있는가?
- 반응, 다음 상태: 화상통화가 끝나면 종료하기를 누르고 창을 닫는다.
4. 학습한 영어 복습
- 행동, 이벤트: 게임하기 버튼을 클릭해 영어 단어를 입력하며 게임을 진행한다.
- 조건: 영어 단어와 문장을 입력하며 게임 조건에 달성하였는가?
- 반응, 다음상태: 점수판을 확인하고 랭킹을 확인한다.
                확인을 눌러 완료 안내로 이동한다.
5. 완료와 다시 설정
- 행동, 이벤트: 완료 안내를 읽고 필요하면 '다시 설정하기'를 클릭한다.
- 반응, 다음 상태: 설정 상태를 확인하고 다음 영어 단어와 문장 학습하기 또는 종료하기를 누른다.
                이미 확인한 카메라 활용 동의와 다른 기능을 유지한다.
